# אמירו גרין — פרויקט לניהול צוותי אבטחה

מגיש: **מוחמד בדארנה**. חבילת קוד ותיעוד להגשה אקדמית, עם טיוטות אפיון, דוח ומצגת. עודכנה ב־10/10/2026. מציגים את הפרויקט ב־14/10/2026.

המערכת מרכזת זמינות עובדים, בקשות לקוחות, בדיקת מנהל, הצעת סידור עבודה, אישור סידור, דיווח שעות וסיכומי כספים. הממשק בעברית. ההתחברות המקומית ונתוני הפתיחה מיועדים להדגמה.

## דרישות הקורס ומצב ההגשה

ההנחיות שסיפק הסטודנט דורשות שלושה תוצרים למודל: מסמך פרויקט PDF/MD בשישה פרקים, תרחיש עובד מהתחלה ועד הסוף ומצגת PDF/PPTX. נדרשת גם הקלטת מסך של עד שתי דקות כגיבוי. משך ההצגה הוא 10-15 דקות ועוד שאלות. לפי דברי הסטודנט המרצה ביקשה בעל פה GitHub וצילומי Make; בקובץ ההנחיות ניתן למסור את המערכת באמצעות קישור לגיט/דרייב או קבצים. בתיקיית submission נמצאות טיוטות הדוח, ה־PRD והמצגת. ה־PRD נוסח מתוך הפרויקט; נתוני העלות והזמן הם הנחות מסומנות. בוצעה הרצת Make AI אמיתית מקלט מלאכותי ידני למאגר בדיקה. קליטת האתר ובדיקת המנהל עדיין ממתינות לאימות. אין עדיין הקלטת חובה, פרסום GitHub או הגשה במודל.

ראו [מפת דרישות והשלמות](מפת%20דרישות%20והשלמות.md) לרשימה המדויקת ולמצב כל תוצר. משתמשים רק בנתונים מלאכותיים או מוסתרים ומציינים את השימוש ב-AI. ההפעלה המסחרית תישאר שלב נפרד.

## הפעלה מקומית ב־Windows

1. הורידו או שכפלו את כל המאגר למחשב, וחלצו אותו אם הורד כ־ZIP.
2. נדרשת התקנה של Node.js בגרסה 22.13 ומעלה. בהפעלה הראשונה נדרש אינטרנט להתקנת התלויות.
3. מסייר הקבצים הפעילו **פתיחת האתר.cmd**. ההכנה הראשונה עשויה להימשך כמה דקות.
4. פתחו את כתובת האתר שמופיעה בחלון ההפעלה. השאירו את החלון פתוח בזמן העבודה. הכתובת והפורט נקבעים בכל הפעלה.

אפשר גם להפעיל מתוך תיקיית source:

```powershell
node scripts/start-local.mjs
```

מפתחות אינם נדרשים לצפייה מקומית בנתוני ההדגמה. Make וה־AI החיצוני כבויים כברירת מחדל. לחיבור חיצוני יש להגדיר חשבון בדיקה, הרשאות ומפתחות שרת לפי owner-setup/README.md, ואז לבדוק מסירה בפועל.

## תהליך המערכת

זמינות: Google Form → גיליון תשובות → Make Data Store → סנכרון האתר → בדיקת זמינות ואישור מנהל.

דואר: Gmail → Make → חילוץ AI ושמירת המקור → אישור קבלה בעברית → בדיקת בקשה באתר → דרישות עבודה → הצעת שיבוץ → אישור נפרד וייצוא.

האתר המקומי קורא את המאגר של Make; אין צורך ב־webhook ציבורי למחשב לצורך נתיב זה. מנוע השיבוץ מבוסס על כללים. חילוץ הדואר ב־Make ועוזר AI אופציונלי באתר הם רכיבים נפרדים.

הקלט מתאר חברת ואולם הדגמה, מאבטח אחד ב-10/10/2026 בשעות 12:00–16:00, בתעריף 80 ₪ לשעה. השם והטלפון שחולצו כוללים נקודה בסופם ולכן דורשים בדיקה. זו מדידת הרצה טכנית אחת; נתוני ROI נשארים הנחות. בתחילת הבדיקה אושרה תוכנית Make Core והקצאה של 10,000 קרדיטים.

## מצב החיבורים וגבולות הגרסה

מסמכי source/README_ORIGINAL.md, owner-ready-manifest.json ו-source-copy-manifest.json נשמרו כרקע היסטורי. חלק ממצבי ההפעלה וגרסאות הקוד המתוארים בהם שייכים להכנות קודמות. מדריך זה וקטלוג מפת הקבצים.json מתארים את חבילת ההגשה הנוכחית; אין להשתמש ברישומי הגיבוב ההיסטוריים כדי לאמת אותה.

האתר המקומי נצפה בפועל בדפדפן. בבדיקת Make מ-10/10 אושרה תוכנית Core, והניסוי הידני המלאכותי דרך AI ועד מאגר בדיקה הושלם. הרצה מלאה של Forms/Gmail → Make → אתר עדיין לא אומתה. קובצי make-reference הם חומרי עזר; הם אינם קובצי blueprint שאומתו לייבוא ישיר ואינם מעבירים הרשאות Google.

נדרש לבדוק גם את תזמון הקליטה: המקור יכול להישמר לפני פלט ה-AI. תיקון הקליטה צריך לוודא שהטיוטה באתר כוללת את החילוץ שהושלם; אישורו בהדגמה עדיין ממתין לאימות. אין במימוש שליחה אוטומטית של סידור מאושר לעובדים. העותק המקומי של בקשות הדואר אינו מסנכרן החלטות מנהל מהאתר או שינויים ב־Excel בחזרה לאתר.
