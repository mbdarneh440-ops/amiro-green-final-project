# נתונים מקומיים מלאכותיים בלבד

מצורפים רק נתוני הדגמה שנבחרו במפורש. אין תיבת דואר חברה אמיתית או מסד נתונים מקומי קיים. תיקייה זו אינה הוכחה להרצת Gmail/AI בפועל. הנתונים ומצבי אישור הקבלה בדוגמאות מדומים. ראו README.md להסבר על JSON/CSV, יצירת XLSX האופציונלית והגדרת הבעלים המוגנת לשימוש עתידי. החלטות המנהל ועריכות Excel ידניות אינן מסתנכרנות אוטומטית עם האתר.
