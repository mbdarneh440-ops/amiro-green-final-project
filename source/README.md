# אמירו גרין — קוד המקור המקומי הנוכחי

קראו תחילה את `../00_owner-handoff-guide.md` ואת `../owner-setup/README.md`. זהו עותק המקור הנוכחי לאחר יישום שינויי החיבורים המקומיים; ראיות הבדיקות הסופיות נמצאות ב-`../validation/`. קובצי הקוד שנכללו הם עותקים זהים ברמת הבתים; ה-README המקורי נשמר בנפרד, עם הסרת מזהים מההפניות בעותק המסירה בלבד.

החבילה אינה כוללת קובצי סביבה אמיתיים, מסד נתונים מקומי, פלט הפעלה או פרטי גישה. מעטפות `node.cmd` ו-`npm.cmd` הישנות הושמטו. השתמשו ב-`הפעלה.cmd` או ב-`node scripts/start-local.mjs` עם Node.js בגרסה 22.13 ומעלה. קובץ `.openai/hosting.json` הציבורי היחיד נדרש ל-Vite ולבנייה ואינו פרט גישה. ההתחברות המקומית המדומה והגישה ב-loopback אינן אימות של חברה באתר מתארח.
