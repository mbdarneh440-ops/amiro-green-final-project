מגיש: מוחמד בדארנה

נכון ל-10/10/2026: הרצת Make AI מקלט ידני מלאכותי למאגר בדיקה הצליחה. אימות האתר והחלטת המנהל, ההקלטה ופרסום GitHub עדיין ממתינים להשלמה. הבחירה בין מאגר פרטי לציבורי עדיין פתוחה.

מצב ההרצה והתוצרים נרשם ב-README.md וב-validation/אימות חבילת ההגשה.json. הכנת חבילה מקומית אינה פרסום ב-GitHub או הגשה במודל.

1. במודל מצרפים את מסמך הפרויקט, המצגת והקלטת ההדגמה. המסמך והמצגת נמצאים ב-submission; שמות הקבצים כוללים את שם המגיש ואת שם הפרויקט. ההקלטה צריכה להיות עד שתי דקות.
2. למסירת המערכת מצרפים קישור למאגר GitHub או את חבילת הקבצים, בהתאם להנחיות הקורס. הקוד נמצא ב-source; הוראות ההפעלה נמצאות ב-README.md. הקוד כולל תבניות הגדרה ריקות ואפשר לפתוח את האתר עם נתוני הדגמה גם ללא מפתחות.
3. אם מוסרים דרך GitHub, מעלים את תוכן החבילה — source, submission, evidence, validation וקובצי ההסבר — ולא את תיקיית העבודה הפרטית. במאגר פרטי מוודאים שלמרצה יש גישה; אין בהנחיות הכתובות דרישה למאגר ציבורי.
4. לפני ההגשה פותחים את הקישור המוגש ובודקים את מסמך הפרויקט, המצגת, קובצי הקוד וההקלטה. קישור למחשב המקומי, כגון localhost, אינו קישור שהמרצה יכולה לפתוח במחשב שלה.
5. צילומי Make נמצאים ב-evidence. כל צילום מתואר כתכנון שמור או כתוצאת הרצה. צילום תכנון אינו הוכחת הרצה ואינו מחליף את הקלטת החובה.
6. ההדגמה האקדמית משתמשת בנתונים מלאכותיים. במסמכי האימות מצוין במפורש איזה מסלול הורץ ואילו חיבורים עדיין לא נבדקו מהתחלה ועד הסוף. הרצה ידנית של בקשת בדיקה אינה מוכיחה קליטה מ-Gmail או שליחת Google Form.
7. להפעלה במחשב Windows מחלצים את החבילה ומפעילים את פתיחת האתר.cmd. משאירים את חלון ההפעלה פתוח ופותחים את הכתובת שהוא מציג. נדרש Node.js 22.13 ומעלה; בפעם הראשונה דרוש אינטרנט להתקנת תלויות.
8. שומרים עותק מקומי של המצגת וההקלטה לקראת ההצגה ב-14/10/2026. תרגול ההצגה הוא 10–15 דקות ועוד שאלות, כולל תרחיש הדגמה אחד.

מפתחות, קובצי .env אמיתיים, נתוני לקוחות וסביבת הרצה פרטית אינם חלק מההגשה. הפעלת החברה בפועל נשארת שלב נפרד. חישובי ה-ROI הם הנחות תכנון מסומנות, ולא תוצאות חיסכון שנמדדו בחברה.
