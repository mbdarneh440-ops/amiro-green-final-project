חסר עדיין סרטון: נדרשת הקלטת מסך אמיתית של עד שתי דקות. צילום Make ונתוני הקליטה אינם מחליפים את ההקלטה. אין בחבילה סרטון, ולא בוצעה הגשה במודל.

מה עבד בפועל: קלט מלאכותי ידני → Make AI → JSON → מאגר בדיקה → קליטה אוטומטית בשרת האתר כבקשה שממתינה לבדיקה. קריאה מאומתת של שרת Desktop החזירה HTTP 200 וגרסת מצב 2. אישור מנהל, יצירת עבודה ושיבוץ עדיין לא אומתו בניסוי זה. Gmail, הגשת Forms ושליחת דואר לא נוסו מהתחלה ועד הסוף.

1. במודל מצרפים את מסמך הפרויקט MD, המצגת PDF והקלטת ההדגמה עד שתי דקות. קובצי המסמך, PRD והמצגת נמצאים בראש החבילה וגם בתיקיית submission, עם שם המגיש והפרויקט.
2. למסירת המערכת מצרפים את קישור GitHub: https://github.com/mbdarneh440-ops/amiro-green-final-project . המאגר ציבורי ופורסם; הקוד ומסמכי המסירה מצורפים גם בחבילה. אפשר לצרף את ZIP הקוד אם מקום ההגשה מאפשר זאת.
3. צילום Make האמיתי נמצא ב-evidence. ראיות ההרצה, הקליטה והפרסום נמצאות ב-validation. כל ראיה מתארת במפורש את מה שנבדק ואת הגבולות.
4. לפני ההגשה משלימים חזרה על החלטת מנהל ושיבוץ עם מידע מלאכותי ומקליטים מסך אמיתי. שומרים את הסרטון, בודקים שאפשר לפתוח אותו ושמשכו אינו עולה על שתי דקות. יש להשלים את שלבי המנהל שנדרשים לתרחיש שבוחרים להציג.
5. להפעלה ב-Windows מחלצים את כל החבילה ומפעילים את פתיחת האתר.cmd. משאירים את חלון ההפעלה פתוח ופותחים את הכתובת המוצגת. נדרש Node.js 22.13 ומעלה; בהפעלה הראשונה דרוש אינטרנט להתקנת התלויות. ללא הגדרות פרטיות אפשר לצפות בנתוני ההדגמה; חיבור Make חיצוני דורש הגדרות שרת אישיות.
6. אחרי העלאה במודל פותחים את כל התוצרים והקישור, ואז שומרים אישור הגשה. הכנת ZIP ופרסום GitHub אינם הגשה במודל. localhost אינו קישור שהמרצה יכולה לפתוח מהמחשב שלה.
7. לקראת ההצגה ב-14/10/2026 שומרים עותק מקומי של המצגת והסרטון ומתרגלים הצגה של 10–15 דקות ועוד שאלות.
