CODE — כל קוד הפרויקט

source/app/: דפי האתר, העיצוב הכללי ונתיבי API של השרת.
source/components/: ממשק האתר, העובדים, הטבלאות, הייבוא, העוזר והחיבורים; ui/ מכיל רכיבי ממשק משותפים.
source/lib/: כללי העבודה, ההצעות, האישור, הייבוא, חיבורי Make ו-AI ושמירת הנתונים.
source/db/ ו-source/drizzle/: הגדרת מסד הנתונים, מבנה טבלת סביבת העבודה ומיגרציות.
source/public/: סמלים, לוגו האתר ותבניות CSV לייבוא עובדים, אתרים ואירועים.
source/scripts/ ו-source/build/: הפעלת העותק המקומי, התקנת הספריות, בנייה ובדיקות.
source/tests/: בדיקות לכללי העבודה, לחיבורים ולייבוא.
source/desktop/: מקור מעטפת Windows וכלי הבנייה שלה; אין בתיקייה קובץ EXE מוכן.
source/vendor/: חומרים מצורפים של צד שלישי והרישיונות שלהם.
לכל קובץ בתיקיות האלה יש תיאור ב-התחילו כאן.html וב-מדריך הקבצים.txt. שמות הקוד והנתיבים המקוריים נשמרו כדי שהייבוא יישאר תקין; השמות הפשוטים בשורש התיקייה משמשים כנקודות כניסה נוחות.
זהו עותק מסירה עצמאי: הוא אינו משנה את הפרויקט המקורי ואינו כולל ספריות מותקנות, מסד נתונים של המחשב או מפתחות אמיתיים. SITE מתקין ספריות ובונה לפי הצורך.
