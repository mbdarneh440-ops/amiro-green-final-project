API KEY — היכן מזינים את המפתחות?

פתחו את מפתח API.cmd בסייר הקבצים. הכלי מבקש את כתובת הדוא״ל של החברה, מזהה מאגר Make, האזור, מפתח Make ומפתח AI אופציונלי. המפתחות מוסתרים בזמן ההקלדה בחלון ההגדרה.
הקוד שקולט את המפתחות: owner-setup/configure-owner.mjs, ובמיוחד שתי הקריאות ל-readMaskedSecret עבור Make ו-AI. הוא שומר את הגדרות העותק הזה בקובץ source/.env. תבנית המשתנים הריקה נמצאת ב-source/.env.example; שם מפתח OpenAI שהפרויקט קורא הוא AI_API_KEY.
אין מפתחות אמיתיים בתיקייה הזאת. אין להכניס מפתח לקוד או ל-owner-inputs.example.json; הקובץ האחרון מסביר את שדות הקלט בלבד.
אם source/.env כבר קיים, למשל לאחר פתיחת SITE בפעם הראשונה, הכלי נעצר בלי לשנות אותו. להחלפה מכוונת של כל ההגדרות, סגרו את האתר, פתחו Terminal מתוך התיקייה הזאת והפעילו:
  .\"מפתח API.cmd" --replace
האפשרות הזאת מחליפה את כל הגדרות .env בערכים החדשים; בדקו את משתני החברה לפני בחירת ההחלפה.
לאחר שמירת ההגדרות, סגרו את האתר ופתחו שוב את פתיחת האתר.cmd כדי שיקרא אותן.
השירותים נשארים כבויים: AI_ENABLED=false ו-MAKE_SYNC_ENABLED=false. הפעלה בפועל דורשת אישור, חיבור Google ובדיקת גישה; ראו owner-setup/README.md לאפשרויות ההפעלה המפורשות.
מפתח AI כאן משמש את עוזר האתר. חילוץ בקשת דוא״ל ומענה בעברית מוגדרים בתהליך Make, ועשויים לדרוש שירות AI ויתרה בחשבון Make בנפרד.
הפקודה .\"מפתח API.cmd" --help מציגה את הוראות הכלי בלי לכתוב הגדרות.
